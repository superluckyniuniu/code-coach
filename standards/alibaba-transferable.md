# 阿里手册可迁移规约（脚本/Python 适配）

来源：《阿里巴巴 Java 开发手册》思想（命名、异常、安全、注释、控制语句、集合、MySQL）。级别：【强制】必须指出；【推荐】有余力再提。

引用短名写在校验意见里，例如：`命名-见名知意`。

## 命名

| 短名 | 级 | 原意 → 脚本写法 |
|------|----|-----------------|
| 命名-见名知意 | 强制 | 名字能看出用途；禁止 `a1`/`tmp2` 当长期变量 |
| 命名-禁拼音混用 | 强制 | 禁止中英拼音混用无意义拼接 |
| 命名-类驼峰 | 强制 | 类名 `UpperCamelCase` |
| 命名-函数蛇形 | 强制 | 函数/变量 `lower_snake_case`（Python） |
| 命名-常量大写 | 强制 | 常量 `UPPER_SNAKE` |
| 命名-布尔前缀 | 推荐 | 布尔语义用 `is_` / `has_` / `can_` |

## 格式与结构

| 短名 | 级 | 脚本写法 |
|------|----|----------|
| 格式-空格缩进 | 强制 | 4 空格；禁 Tab（Python 以 `python-mysql-format` 为准） |
| 格式-import分组 | 强制 | 标准库 / 第三方 / 本地，组分隔空行 |
| 格式-顶层空行 | 推荐 | 顶层函数之间空两行 |
| 格式-少魔法值 | 强制 | 重复字面量抽成命名常量 |

## 注释

| 短名 | 级 | 脚本写法 |
|------|----|----------|
| 注释-公共接口 | 强制 | 对外函数有一行以上 docstring：做什么、关键参数/返回 |
| 注释-说为何 | 推荐 | 复杂分支注释写「为什么」，不写「做了什么」的复述 |
| 注释-禁废话 | 强制 | 禁止 `i++  # i加1` 类无信息注释 |

## 异常与日志

| 短名 | 级 | 脚本写法 |
|------|----|----------|
| 异常-禁裸except | 强制 | 禁止 `except:` / 无差别吞掉；至少 `except Exception` 且记录 |
| 异常-勿吞掉 | 强制 | catch后要么处理、要么记录后上抛/返回明确错误 |
| 异常-信息可查 | 强制 | 失败信息含操作上下文（URL/表名/关键 id），忌只写 `error` |
| 日志-分级 | 推荐 | 正常用 info/print 节奏；失败用明确 ERROR 前缀或 logging |

## 安全

| 短名 | 级 | 脚本写法 |
|------|----|----------|
| 安全-密钥环境变量 | 强制 | app_secret、密码、token 走环境变量；禁止提交进仓库 |
| 安全-输入校验 | 强制 | 外部/用户输入先校验再使用 |
| 安全-SQL参数化 | 强制 | 禁止把未信任字符串拼进 SQL；用参数绑定 |
| 安全-少暴露细节 | 推荐 | 对外响应不返回堆栈或密钥片段 |

## 控制语句与集合

| 短名 | 级 | 脚本写法 |
|------|----|----------|
| 控制-卫语句 | 推荐 | 前置校验失败早 `return`，降低嵌套 |
| 控制-嵌套不过深 | 推荐 | 超过约 3 层考虑拆函数 |
| 集合-勿边遍历边改 | 强制 | 遍历 list/dict 时不要原地删改同一结构 |
| 集合-分清None与空 | 强制 | `None` 与 `[]`/`{}` 语义分开处理 |

## MySQL（涉及库表时）

| 短名 | 级 | 脚本写法 |
|------|----|----------|
| SQL-排版 | 强制 | 交给 `python-mysql-format`（关键字小写、前置逗号等） |
| SQL-少select星 | 推荐 | 明确列清单，避免无必要 `select *` |
| SQL-索引意识 | 推荐 | where/join 字段是否有索引；大结果要限制或分页 |

## 真实脚本工程化（手册外、本教练强制习惯）

| 短名 | 级 | 含义 |
|------|----|------|
| 脚本-入口清晰 | 强制 | 有明确入口（`main` / handler），副作用不散落模块 import 时执行 |
| 脚本-资源关闭 | 强制 | DB/文件/session 用完关闭或 `with` |
| 脚本-批次超时 | 推荐 | 批量 API 注意分页/批大小；网络设超时 |
| 脚本-失败可观测 | 强制 | 关键步骤有日志或 print，失败能定位到哪一步 |
